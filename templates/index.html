Вопросы

Частые вопросы.

Что такое VLESS Reality?
Современный протокол, который маскирует подключение под обычный HTTPS к крупному сайту. Со стороны оно выглядит как привычный трафик, поэтому его сложно распознать и заблокировать.
На скольких устройствах можно пользоваться?
{% if max_keys == 1 %}На одном: одна подписка даёт один ключ для одного устройства. Чтобы перейти на другое устройство, удалите ключ в кабинете и создайте новый.{% else %}До {{ max_keys }} устройств на один аккаунт. Для каждого устройства создаётся свой ключ, ненужный можно удалить в кабинете и создать новый.{% endif %}
{% if device_limit %}
Можно ли дать ключ другу?
Нет. Ключ работает только на одном устройстве одновременно. Если пользоваться им на двух устройствах сразу, ключ отключится на {{ ban_minutes }} минут, а при повторном нарушении будет удалён без возможности создать новый. Другу лучше оформить свою подписку.
{% endif %}
Какие приложения нужны?
На iPhone и iPad: v2RayTun или Streisand из App Store. На Android: v2rayNG или Hiddify. На Mac и Windows: Hiddify с сайта hiddify.com.
Подписка продлевается автоматически?
Нет. Вы платите только за выбранный срок. Если продлить заранее, новые дни добавятся к текущей подписке.
Что будет, когда подписка закончится?
Ключи отключатся автоматически. Аккаунт останется: оплатите любой тариф и создайте ключи заново.
